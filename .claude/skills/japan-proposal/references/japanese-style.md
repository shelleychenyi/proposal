# 日文提案書的寫法

對象是日本企業的決策者。基準是 Intasect 名義交付的實際提案書。
**不要用中文語序直翻。** 中文寫「我們幫你把聲量提升 30%」，日文要寫
「口コミ接点の拡大を、声量＋30％で確認します」——主語落在「事」不落在「我們」。

## 語體

- **です・ます体**，全篇統一。不要混入だ・である体。
- 主動承諾用「〜します」「〜いたします」；對客戶的行為用「ご確認いただきます」。
- 自稱：**当社**（本文中）／**弊社**（信件與寒暄）。對方：**貴社**。
- 「御中」只出現在封面的收件方；本文不用。
- 避免「〜と思います」「〜かもしれません」。提案書要斷定：「〜です」「〜と考えます」。
- 一句話不超過 60 字，超過就斷句。日文提案的閱讀節奏比中文短。

## 標題命名

範本已固定為「N.○○」的形式，沿用參考提案的詞彙即可：

| 頁 | 標題 |
|---|---|
| p2 | 1.台湾消費者の行動特徴 |
| p3・p4 | 2.Pandora 台湾市場レポート |
| p5 | 3.企画案概要 |
| p6 | 3.企画案概要｜ターゲット設計 |
| p7 | 4.実施スケジュール |
| p8 | 5.コンテンツ設計 |
| p9 | 5.投稿サンプル |
| p10 | 6.効果指標・目標値 |

同一章跨兩頁時共用同一個數字。標題是**名詞句**，不要寫成句子。

## 數字的寫法

- 半形數字＋全形單位：`261,739件`、`85,693件`、`約11.9％`
- 千分位一律加逗號
- 年月日：`2026年9月1日（火）`；區間用 `〜`（波浪），不用 `~` 或 `-`
- 範圍數值：`2,500〜5,000人`
- 百分比用 `％`（全形），不用 `%`
- 金額：`¥5,950,000（税別）`——**日本客戶一定要標「税別」或「税込」**

## 出典（每一頁都要有）

格式：

```
出典：Pandora by The Pocket Company／Accucrazy「【案件名】声量レポート」（データ期間：yyyy年m月d日–yyyy年m月d日）
※ 総声量は、いいね・コメント等の反応を加重集計したPandora独自指標です（10＋いいね×3＋コメント×5）。
```

外部統計要寫全名：`日本政府観光局（JNTO）「訪日外客数」`、
`台湾行政院人事行政総処「政府行政機関カレンダー」`。

**沒有出典的數字不要放上簡報。**

## 保證與參考值的措辭（合約風險，務必分清）

| 類別 | 日文措辭 | 註記 |
|---|---|---|
| 保証 | 「〜を保証します」「未達成の場合は該当金額の30%を返金します」 | 一定要寫未達成時的處置 |
| 目標値 | 「〜を目標として設定しています」「同類実績に基づく努力目標です」 | 明寫非合約保證值 |
| 承諾交付 | 「〜を納品します」「〜本を制作します」 | 數量與交付物 |

頁尾必寫的免責：

```
※ 目標値のうち「声量＋30％」のみ保証値です。その他は施策設計上の参考値として設定しています。
```

**絕對不要**把目標值寫成「保証」。日本客戶會照字面理解並寫進合約。

## 提案書的口氣示範

差：
> 台湾ではThreadsがとても人気なので、Threadsで投稿すれば効果が出ます。

好：
> Threadsは台湾が世界トラフィックの22%を占め、月間アクティブユーザーは約350万人。
> フォロワー外にも投稿が届くアルゴリズムのため、開始初月から接点を創出できます。

差：
> 弊社は口コミマーケティングが得意です。

好：
> 口コミ先行、広告で刈り取り、Pandoraで全期間モニタリング。
> 三本の線を一つのパッケージとして運用します。

**主張 → 根拠（数字） → 打ち手** 的順序。形容詞少，數字多。

## 繁中版的差異

`template_zh` 用微軟正黑體，數字與拉丁字維持 Meiryo，外觀一致。
繁中版是給台灣端內部對稿用的，措辭可以直接一點，但數字與出典規則完全相同。
封面收件行日文用「【クライアント名】　御中」，繁中用「【客戶名】　敬呈」。
