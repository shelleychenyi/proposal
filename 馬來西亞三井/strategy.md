## 3. 痛點表

| | 障礙點 | 機會點 |
|---|---|---|
| 年輕會員 | 點數只會「累積」、看不到進度；遊戲藏在 Profile 第二層；首頁只是一面廣告牆 | 他們已經天天來看動漫、K-pop、聯名咖啡——只差一個「收集」的理由 |
| 商場（LaLaport／MOP） | 95% 消費沒被記到會員身上，CRM 是空的；兩館共用 App 卻沒有共用的身份感 | 每一張發票都是會員數據；等級制能把「偶爾來」變「每月來」 |
| 店家 | 好評散在 IG／Threads，商場 App 裡看不到 | 把網路好評搬進 App，變成館內導購 |
| 挑戰 | 拍發票集點的作業量、店家 POS 不通、口碑內容的真實性 | AI 發票辨識、騰雲 POS／CRM 串接、Pandora 好評＋已購認證的 Real Talk |

## 4. 策略

- **Product Truth**：LaLaport BBCC 是吉隆坡最「日本」、最有 ACG 與活動能量的商場；MOP KLIA 是機場旁唯一的 Outlet。同一個 App 串兩館。
- **Fan Truth**：年輕人不是不來，是來了沒被記住。「停車費比我的積蓄還貴」——最痛的事，App 其實早就有解法，只是沒人知道。
- **Cultural Relevancy**：馬來西亞年輕人每天在 Shopee 玩小遊戲換 Coins；日本的 スタンプラリー（集章）與扭蛋文化，是 LaLaport 最自然的遊戲語言。
- **三個切角**：
  1. 看得到進度（等級制 + 進度條 + 停車時數隨等級升級）
  2. 玩得到東西（Quest 任務、集章、數位扭蛋）
  3. 問得到答案（AI 管家 + 口碑專區 LaLa Buzz）
- **Proposition**：每一次來，都在升級。（Every visit levels you up.）
- **IDEA**：**LaLa Quest｜把逛街變成一場升級遊戲**
  - 一個 App，四件事：
  - Level Up：Rookie → Explorer → Senpai → Legend 四級會員（取代單一 Regular Member）
  - Play：每日簽到、館內 Quest、Stamp Rally、數位扭蛋 Capsule
  - Ask：AI Concierge「Ask LaLa」+ AI 發票掃描集點
  - Buzz：LaLa Buzz 口碑專區——Pandora 爬網路好評、AI 摘要、已購認證分享 Real Talk
- **OUR PICK**：只做一案。分岔放在 Activation（ACG Season Pass、Bon Odori Matsuri Pass、KLIA Transit Quest）。
